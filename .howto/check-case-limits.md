# Проверить дела против правил

```sh
./bin/el check        # дело в руках (и его вложенные дела); или `el check`, если el в PATH
./bin/el check --all  # все дела пространства; legacy-дело — одной строкой на файл с recovery (`el --case X migrate`), не дампом его ошибок
```

Печатает нарушения (`x …`, правило и строка) в stdout и предупреждения в stderr; выход `3`, если есть хоть одно нарушение. Что проверяет — грамматики README / TODO / JOURNAL / файлов фаз (F0–F13), отпечатки (S1), файлы `.recover.md`, вложенные дела. Каждое нарушение дописывается в `.cases/checks.log` — сырьё для `review`.

Нарушение чинится по `.cases/RULES.md`: README — секция уходит в файл; событие журнала — детали в тело под строкой; фаза без RESULT — дописать, что она дала; `*.recover.md` — внести строки командами `el` и удалить файл.
