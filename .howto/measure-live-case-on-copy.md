# Замерить живое дело на копии, не трогая оригинал

Признак: нужно увидеть, что текущий `el` скажет о живом деле — Order, `check`, какие строки он перерисует, — но в живом проекте `el` запускать нельзя: вход переписывает README. Функции библиотеки на оригинале тоже не чтение наверняка: дверь отпечатка (`store.load`, `store.todo_of`) при расхождении отпечатка пересобирает файл, то есть пишет.

```sh
rsync -a --exclude .git ~/work/some-project/ "$TMPDIR/copy/"   # копия без истории — секунды даже на десятках MB
cd "$TMPDIR/copy" && EL_SESSION=copy el                        # вход как у владельца: нитка, Order, подсказки
EL_SESSION=copy el check --all                                 # нарушения по всем делам копии
diff -rq ~/work/some-project "$TMPDIR/copy" -x .git            # что вход перерисовал
```

Как читать: `Order ✓` и `check … violations: 0` — дело в текущей форме; пустой `diff` — вход не изменил ни байта. Файл в `diff` — строка, которую `el` писал раньше и теперь пишет иначе (старая форма своей же записи): в оригинале она перерисуется при следующей записи, чинить руками не нужно. `EL_SESSION=copy` держит руку копии отдельно от рабочих сессий.

Правку `el` мерить на той же копии до и после: старый `el` — `git archive HEAD elephant bin elephant.py | tar -x -C "$TMPDIR/old"`, запуск `"$TMPDIR/old/bin/el"`.

Не делать: `el` в оригинале ради замера; вызовы библиотеки на оригинале, если отпечаток может не сойтись.
