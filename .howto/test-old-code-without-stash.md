# Старый код проверять копией, а не git stash

**Что случилось.** Чтобы показать, что новый тест падает на старом коде, сделали `git stash` → прогон → `git stash pop` одной командой. Python за ту же секунду записал байткод `__init__.py` со старой строкой версии. Строки `1.74.0` и `1.75.0` одной длины, а время файла после `pop` совпало с временем `stash` до секунды — проверка кэша (время + размер) сочла его свежим, и `el --version` дальше печатал старую версию. Нашла это вторая рука при приёмке, а не прогон тестов. Вдобавок `stash` прячет и правки других сессий в том же дереве.

**Как правильно.** Старый код — отдельной копией, рабочее дерево не трогать:

```
D=$(mktemp -d) && git archive HEAD elephant bin elephant.py tests | tar -x -C "$D"
cp tests/<новый тест>.py "$D/tests/" && (cd "$D" && python3 -m unittest tests.<новый тест>)
```

**Если уже случилось.** `touch elephant/*.py` — время файлов сменится, кэш перестроится при следующем запуске; удалять `__pycache__` не нужно. Проверка: `./bin/el --version` совпадает с `elephant/__init__.py`.
