# elephant-cli

`el` — бухгалтерия работы агента над задачей: состояние живёт на диске, а не в памяти сессии. Хранилище `.projects` в корне проекта, восемь фаз от сбора контекста до закрытия, переходы с доказательствами, HTML-витрины для человека, автономия как кредит слова, долг владельца, отзывы об инструменте. Инструмент не привязан к конкретному агенту: Claude Code, Codex, Copilot — любой, кто умеет запускать команду.

## Установка

```sh
git clone https://github.com/MykhailoDmytriakha/elephant-cli
./elephant-cli/install.sh        # ~/.local/bin/el → клон; клон может лежать где угодно
```

Обновление — `git pull` в клоне: команда, шаблоны страниц и guide приходят одним движением. Только Python 3, без зависимостей.

## Подключение к агенту

`install.sh` агентов не трогает — на машине может не быть того, которого вы ждёте. Папка `skill/` — один и тот же скилл для любого harness; подключите её сами:

- Claude Code: `ln -s <клон>/skill ~/.claude/skills/elephant`
- Codex CLI: `ln -s <клон>/skill ~/.codex/skills/elephant`
- Copilot и прочие: вставьте `skill/SKILL.md` в файл инструкций агента или сошлитесь на него

Скилл — только дверь: вся инструкция живёт в самом CLI. `el` без аргументов — онбординг; `el blueprint` — закон целиком; `el next` — следующий ход.

## Что где

| | |
|---|---|
| `cli/` | команда `el`: вход `el.py`, пакет `el/`, дифф-тест `tests/scenario.py` |
| `html/` | шаблоны витрин — все проекты · один проект |
| `skill/` | `SKILL.md` — вход для агента |
| `elephant-guide.md` | эталон: Elephant, каким он должен быть; при расхождении прав он |
| `ideas.md` | непринятые варианты и идеи — не в guide |
| `feedback/` | pool отзывов об инструменте (`el feedback`), под git — едет между машинами |

## Проверка

```sh
python3 cli/tests/flow.py                     # одна задача через все восемь фаз на записях — держит или нет
python3 cli/tests/flow.py --upto plan --out /tmp/f --serve 8770   # остановиться после плана и посмотреть страницу
python3 cli/tests/flow.py --from execute --out /tmp/f             # продолжить из того же хранилища
python3 cli/tests/scenario.py run --bin cli/el.py --out /tmp/snap-new   # дифф-тест (ждёт переписи под записи)
```

Хранение с 2026-08-27 — три файла на задачу: `records.jsonl` (все фазы и потоки), `checks.jsonl`
(обещания и вердикты), `journal.jsonl` (события). Ни `plan.md`, ни `nodes/`, ни `validation.md`.
